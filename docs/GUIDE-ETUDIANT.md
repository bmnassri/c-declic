# Guide étudiant
Pilote sur exemples fictifs uniquement. Ouvrir https://c-declic-production.up.railway.app/ et choisir le rôle étudiant. Utiliser le mot de passe transmis par l'enseignant, sans le partager.
1. Cliquer sur Commencer, choisir la notion, renseigner énoncé, code C, erreur facultative et question.
2. Analyser mon code vérifie la saisie uniquement. Confirmer les données fictives puis Envoyer à l'enseignant.
3. Actualiser les demandes ; attendre la validation humaine. Aucun brouillon ne doit être visible.
4. Lire la question, réfléchir, afficher l'indice si nécessaire. Répondre (sans données personnelles) ou demander Indice suivant. Trois niveaux maximum.
5. Signaler une erreur si nécessaire, cliquer J'ai compris ou Nouvelle analyse pour recommencer. Se déconnecter en fin de séance.
Une demande expire au plus tard après une heure ou au redémarrage/déconnexion. Si refus ou blocage, demander de l'aide à l'enseignant. L'IA peut se tromper ; elle ne note pas et n'exécute pas le code.
