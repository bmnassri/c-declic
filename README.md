# C'Déclic

**De l'erreur à la compréhension.**

C'Déclic est un assistant pédagogique intelligent destiné aux élèves ingénieurs de l'ECE qui apprennent la programmation en langage C.

Grâce à une approche socratique fondée sur le questionnement et les indices progressifs, il aide les étudiants à identifier et à comprendre leurs erreurs, à développer leur raisonnement algorithmique et à trouver eux-mêmes les solutions, sans leur fournir directement le code corrigé.

**L'IA te guide, la solution vient de toi.**
